## Typography

### Font Families

- **Headings**: Fredoka (rounded, friendly)
- **Body**: Quicksand (soft, readable)
- **Fallback**: System fonts for compatibility

### Font Weights

- Light: 300
- Regular: 400
- Medium: 500
- Semi-bold: 600
- Bold: 700

## Design Features

### Border Radius

- **Small**: 8px - Inputs, small elements
- **Medium**: 12px - Buttons, badges
- **Large**: 16px - Cards, containers
- **Extra Large**: 20px - Large cards
- **2XL**: 28px - Special elements
- **Full**: 9999px - Circles, pills

### Shadows

All shadows use soft peach tones for a warm, gentle feel:

- **Small**: Subtle depth
- **Medium**: Standard cards
- **Large**: Elevated elements
- **XL**: Modals, dropdowns
- **2XL**: Maximum elevation

### Gradients

- **Background**: Linear gradient from cream to soft peach
- **Primary Buttons**: Peach gradient with glow
- **Secondary Buttons**: Mint gradient with glow
- **Scrollbar**: Peach to mint gradient

## Special Animations

### Available Animations

- **Float**: Gentle up-and-down motion (3s)
- **Fade In**: Smooth appearance with slide up
- **Pulse**: Subtle opacity change
- **Shimmer**: Loading effect
- **Bounce**: Playful bounce (2s)
- **Wiggle**: Gentle rotation on hover

### Usage

```css
.element {
  animation: bounce 2s ease-in-out infinite;
}
```

## Components Style Guide

### Buttons

- Rounded corners (16px)
- Soft shadows with color glow
- Smooth hover transitions
- Gradient backgrounds

### Cards

- Extra rounded (20px)
- Warm cream background
- Soft peach shadows
- Gentle border (2px)
- Hover lift effect

### Forms

- Rounded inputs (12px)
- Soft focus glow (peach)
- Comfortable padding
- Gentle placeholder text

### Avatars

- Circular (border-radius: 9999px)
- Peach border (3px)
- Soft shadow with color
- Gentle scale on hover

## Color Psychology

This baby theme uses:

- **Peach/Coral**: Warmth, comfort, friendliness, energy
- **Mint Green**: Growth, freshness, calmness, harmony
- **Cream**: Softness, gentleness, warmth, comfort

Perfect for creating a welcoming, nurturing environment!

## Implementation Notes

1. All colors use warm undertones
2. Shadows are tinted with brand colors
3. Background has subtle gradient
4. Extra rounded corners throughout
5. Playful animations for interaction
6. Soft, readable fonts
7. Gentle hover effects

---

**Theme Mood**: Warm, gentle, playful, nurturing, and welcoming 🌟
